Урок 1: класс и объект, первая программа на C#
C# — язык программирования, на котором создают игры, приложения для компьютера и сервисы; работаем в программе Visual Studio.
- Класс как шаблон, объект как конкретный экземпляр
- Примеры из жизни: форма для печенья и печенье, модель велосипеда и конкретный велосипед
- Зачем нужно ООП: меньше повторений, проще менять программу
- Установка Visual Studio и создание первого консольного проекта
- Первый класс Robot и три робота-объекта

Урок 2: поля и методы, что объект знает и что умеет
- Поля — данные объекта: имя, цвет, заряд
- Методы — действия объекта: показать сведения, поехать к стенду
- Типы данных: текст, целое число, дробное число
- Заполнение полей и вызов действий робота
- Вывод результата в консоль

Урок 3: конструктор, создаём объект сразу с нужными данными
- Зачем нужен конструктор: объект не должен появляться «пустым»
- Параметры: передаём данные в момент создания
- Слово this: поле именно этого объекта
- Создание нескольких роботов с разными данными

Урок 4: инкапсуляция, объект защищает свои данные
- Идея инкапсуляции: важные данные нельзя менять как угодно
- Свойство: значение можно прочитать, но нельзя изменить напрямую
- Условие «если»: проверка допустимых значений
- Безопасные методы расхода энергии и зарядки
- Заряд робота всегда остаётся в пределах от 0 до 100 процентов

Урок 5: списки объектов, когда объектов становится много
- Список List: вся команда роботов в одном месте
- Добавление объектов в список
- Цикл foreach: одно действие для каждого робота по очереди
- Проверка заряда всей команды: кого пора заряжать
- Свой список: книги, заказы или участники события

Урок 6: абстракция, выбираем главное для задачи
- Абстракция: в программе оставляем только важное для задачи
- Один и тот же робот описывается по-разному для экскурсии и для доставки
- Класс робота-экскурсовода: приветствие, переход в другую зону
- Модель для своего объекта: билет, автобусное табло, автомат заказов

Урок 7: наследование и полиморфизм, общее и разное поведение
- Наследование: общее описываем один раз в родительском классе
- Два класса-потомка: робот-экскурсовод и робот-доставщик
- Полиморфизм: одна команда, но роботы выполняют её по-разному
- Разные роботы в одном списке
- Свои примеры: обычный и льготный билет, книга и аудиокнига

Урок 8: итоговый проект, команда роботов на выставке
- Самостоятельная сборка проекта: общий класс и две роли роботов
- Защита заряда и список команды
- Один запуск работы для всех роботов с разным результатом
- Самопроверка: заряд не может стать больше 100 процентов
- Показ проекта и объяснение, где видны идеи ООП
