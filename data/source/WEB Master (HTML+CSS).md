- Редактор кода Visual Studio Code и открытие страницы в браузере
- Основные теги: заголовки, абзацы, списки, картинки
- Ссылки между страницами и меню навигации
- Создание страницы «Об авторе»
- Подключение файла стилей: цвет фона, отступы, скруглённые углы
