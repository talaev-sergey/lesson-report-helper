Урок 1: знакомство с App Inventor, первое приложение-кликер
App Inventor — онлайн-сервис для создания мобильных приложений из готовых блоков, без написания сложного кода.
- Интерфейс сервиса: дизайнер, компоненты, свойства, блоки
- Кнопка и счётчик нажатий — приложение-кликер
- Блочное программирование: реакция на нажатие кнопки
- Второй экран и переход между экранами
- Проверка приложения на смартфоне

Урок 2: условия и сохранение данных, приложение «пароль»
- Код из 4 цифр, как на кодовом замке
- Условия «если — то — иначе»: цифра меняется от 0 до 9
- Сохранение данных в базе данных на устройстве, чтобы они не терялись после выхода
- Экран входа: доступ к смене пароля только при верном пароле

Урок 3: экраны и передача данных, приложение «Заказ пиццы»
- Выбор типа и размера пиццы из списка
- Несколько экранов и итоговый экран заказа
- Передача данных между экранами
- Словарь: хранение данных по названиям («ключ — значение»)
- Кнопка «Назад» и удаление лишних данных

Урок 4: нейросети для создания приложений, Base44 и Lovable
- Создание приложения по текстовому описанию
- Сравнение двух ИИ-сервисов и правка сгенерированного результата
- Ограничения бесплатного тарифа: токены
- Приложение для проверки реакции: сначала своими руками, затем с ИИ
- ИИ — помощник, а решения и проверку берёт на себя человек

Урок 5: собственное приложение, заметки и расписание
- Приложение для заметок: выбор даты и времени, текст заметки, сохранение
- Проверка заполнения полей и сообщение об ошибке
- Сравнение с версиями от ИИ-сервисов, проверка их работы
- Самостоятельный проект: угадай число, тест или кликер с улучшениями
- Сборка готового приложения для установки на Android
