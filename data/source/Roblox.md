Урок 1: знакомство с Roblox Studio, интерфейс и первые объекты
Roblox Studio — программа для создания собственных 3D-игр на платформе Roblox, в ней же пишут код на языке Lua.
- Регистрация на сайте Roblox, настройка внешнего вида персонажа
- Окна программы: Explorer, Properties, Toolbox, панель инструментов
- Управление камерой и пробный запуск игры
- Создание блоков (Part) и работа с ними: перемещение, размер, поворот, цвет
- Закрепление объектов кнопкой Anchor, чтобы постройка не рассыпалась

Ссылка на сайт:
https://www.roblox.com

Урок 2: ландшафт Terrain и первая игра-шутер
- Работа с картой Flat Terrain и редактором ландшафта Terrain Editor
- Инструменты рельефа: рисовать, выравнивать, перекрашивать, наращивать, сглаживать
- Генерация карты и ограничение краёв, чтобы персонаж не упал
- Точка появления игрока (Spawn)
- Добавление оружия и врагов из Toolbox

Урок 3: основы языка Lua, начало платформера
- Первый скрипт и вывод текста командой print
- Переменные и простые действия с числами и текстом
- Создание объекта из кода и изменение его размера, положения и цвета
- Сообщение на экране, которое исчезает через заданное время
- Создание собственных уровней в платформере

- Случайные числа в коде
- Движущиеся платформы в уровнях платформера

Урок 5: игра Obby, условия и функции
- Знакомство с игрой Obby: уровни с контрольными точками (чекпоинтами)
- Условный оператор if — компьютер принимает решение по условию
- Функции: как собрать набор команд и вызвать его когда нужно
- Опасные блоки, которые убирают здоровье персонажа при касании
- Трамплин, подбрасывающий игрока вверх

Урок 6: диалоги и новые типы уровней в Obby
- Персонаж-помощник (NPC) с диалогом и вариантами ответа игрока
- Многоэтажный Obby с лестницей из блоков
- Свойства CanCollide и Transparency: блоки, через которые можно провалиться, и невидимые блоки
- Движущаяся платформа, управляемая кнопкой и рельсами
- Координаты объекта и их изменение из кода

Урок 7: интерфейс игры и первое меню
- Уровни Obby с готовыми объектами из Toolbox и с опасными блоками
- Уровень «лабиринт из дверей»: одна дверь проходимая, остальные опасные

- Настройка текста, шрифта и цветов
- Стартовое меню с кнопкой «Play!», которая закрывает его по нажатию
