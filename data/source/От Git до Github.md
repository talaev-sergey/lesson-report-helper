Урок 1: что такое контроль версий, установка и настройка Git
Git — программа, которая следит за изменениями в проекте, запоминает каждое сохранение и позволяет вернуться к любой прошлой версии.
- Зачем нужен контроль версий: сохранения как «контрольные точки» в играх
- Краткая история Git и его создатель
- Установка Git и терминала Git Bash
- Первая настройка: имя и e-mail автора
- Установка редактора кода VS Code
Ссылка на сайт Git:
https://git-scm.com
Ссылка на редактор:
https://code.visualstudio.com

Урок 2: первый репозиторий, коммиты и история
- Репозиторий: папка проекта, за которой следит Git
- Путь файла: рабочая папка, индекс, коммит
- Команды init, status, add, commit
- Первый и второй коммит своими руками
- Просмотр истории сохранений

Урок 3: история изменений, отмена ошибок, возврат к версии
- Проект на Python: консольный калькулятор, каждая операция отдельным коммитом
- Просмотр истории и подробностей любого коммита
- Отмена ошибки, которая ещё не сохранена
- Безопасная отмена уже сохранённой ошибки без потери истории
- Временный «переход в прошлое» к старой версии и возврат обратно

Урок 4: ветки, создание, переключение, слияние
- Ветка как отдельная дорожка: черновик рядом с чистовиком
- Новая функция калькулятора в отдельной ветке, не ломая основную версию
- Переключение между ветками и сравнение их друг с другом
- Слияние ветки с основной, в том числе когда обе дорожки изменились
- Удаление ненужных веток

Урок 5: GitHub, аккаунт, отправка проекта в интернет
- Регистрация на GitHub и создание пустого удалённого репозитория
- Локальная и удалённая копии проекта
- Привязка проекта к GitHub и отправка истории командой push
- Забирание изменений с сайта командой pull
- README.md: визитка проекта
Ссылка на сайт:
https://github.com

Урок 6: чужие проекты, clone и fork
- Скачивание готового проекта целиком, со всей историей, командой clone
- Форк: личная копия чужого проекта на своём аккаунте
- Изменение форка и отправка правки в свою копию
- Почему оригинал при этом не меняется
- Ориентация в папках и работа во встроенном терминале VS Code

Урок 7: командная работа, Pull Request, Issues, обзор кода
- Pull Request: предложение автору принять свои изменения
- Issues: задачи и обсуждения внутри проекта
- Обзор кода: комментарии к чужим изменениям по делу
- Полный цикл: задача, ветка, Pull Request, слияние, автоматическое закрытие задачи

Урок 8: итоговый практикум, общий сайт класса на GitHub Pages
- GitHub Pages: бесплатная публикация сайта прямо из репозитория
- Личная страница о себе на HTML по готовому шаблону
- Работа в общем репозитории класса: своя ветка и Pull Request
- Публикация страниц всех учеников на одном общем сайте
- Повторение всего пути модуля: от Git до GitHub
