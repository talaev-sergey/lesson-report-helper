Урок 1: CSS Grid и Flexbox, расположение блоков на сайте
CSS — язык, который отвечает за внешний вид веб-страницы: цвета, шрифты, размеры и расположение блоков.
- Grid: сетка из строк и столбцов, как шахматная доска
- Размеры столбцов и строк: пиксели, проценты, доли fr, функция repeat
- Отступы между ячейками сетки (gap)
- Flexbox: выравнивание элементов в ряд или столбец, главная и поперечная оси
- Практика в играх Grid Attack и Flexbox Adventure: код управляет героями

Урок 2: CSS-селекторы, поиск нужных элементов страницы
- Селектор: правило, которое находит нужные элементы на странице
- Выбор по тегу, классу и id
- Комбинации: потомки, соседи, группировка, «выбрать всё»
- Псевдоклассы: первый, последний, N-й элемент, исключение :not()
- Селекторы по атрибутам
- Практика в квесте CSS Diner и на скоростных тренажёрах
