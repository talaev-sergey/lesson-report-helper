Урок 1: знакомство с PHP, основы языка
PHP — язык программирования для создания сайтов, который выполняется на сервере и умеет работать с базами данных.
- Что такое бэкенд, база данных и SQL
- Вывод текста, переменные, условия
- Циклы, массивы, функции
- Задачи: сумма чисел от 1 до 100, факториал, простые числа, перевод формата даты

Урок 2: закрепление основ PHP, задачи на CodinGame
- Регистрация на сайте CodinGame и знакомство с интерфейсом
- Решение задач на PHP в игровой форме
- Clash of Code: соревнование на скорость в общей группе
- Режимы: самый быстрый, самый короткий код, угадай условие по тестам

Урок 3: знакомство с SQL, детективная игра
- Что такое реляционная база данных: таблицы и связи между ними
- Первичный и внешний ключи
- Выборка данных: SELECT, LIMIT, DISTINCT
- Фильтрация: WHERE, AND, LIKE, BETWEEN
- Сортировка и функции MAX, MIN, SUM

Урок 4: продолжение SQL, расследование убийства в SQL City
- Повторение команд SQL
- Самостоятельный поиск убийцы в учебной игре с помощью запросов
- Поиск свидетелей и чтение протоколов опроса
- Логические выводы на основе данных из нескольких таблиц

Урок 5: создание базы данных и подключение к PHP
- Создание своей базы и таблиц в phpMyAdmin
- Типы данных, автоматическая нумерация, связи между таблицами
- Подключение PHP-скрипта к базе данных
- Запросы INSERT, UPDATE, DELETE из PHP-кода

Урок 6: формы, запросы GET и POST, защита от SQL-инъекций
- Форма на сайте и передача данных на сервер
- Разница между GET и POST
- Что такое SQL-инъекции и как от них защищаться
- Формы, которые добавляют и удаляют строки в базе
- Несколько страниц сайта с переходами между ними

Урок 7: хэширование паролей и куки
- Хэширование: почему пароли хранят не в открытом виде
- Проверка пароля через password_hash и password_verify
- Куки: создание, чтение, удаление
- Практика: таблицы для пользователей, товаров, заказов и комментариев

Урок 8: итоговый проект, создание сайта
- Сайт с собственной базой данных
- Регистрация и вход, пароли хранятся в зашифрованном виде
